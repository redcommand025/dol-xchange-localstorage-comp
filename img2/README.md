## How to use dual spritepacks
The process is very simple:
* Simply copy the contents of vanilla's "img" folder into this current one, which is named 'img2'.
* Then install in 'img2' whatever spritepack you desire, in the same manner you'd normally do for the regular 'img' folder.
* Lastly, in the game, go into Options > Performance, and enable 'Use alternate spriteset when gender is:', then choose which gender to apply the alternate pack to.
